# Panduan Penggunaan JURIST Exam

Selamat datang di halaman resmi JURIST Exam. Berikut adalah panduan singkat cara menggunakan aplikasi ujian ini:

1. **Download Aplikasi**: Unduh file `JURIST Exam.apk` di repository ini[cite: 9].
2. **Instalasi**: Izinkan instalasi dari sumber tidak dikenal (*Unknown Sources*) di HP Anda, lalu instal aplikasinya.
3. **Memasukkan Token**: Buka aplikasi, lalu masukkan kode ujian / token yang diberikan oleh pengawas.
4. **Mulai Ujian**: Pastikan koneksi stabil dan ikuti instruksi ujian sampai selesai.
